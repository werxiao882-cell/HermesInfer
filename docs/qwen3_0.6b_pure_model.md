## 四、Decoder Layer 内部结构 (×28)

```
每个 Decoder Layer 的结构:

  输入: x: (*, 1024)    residual: (*, 1024) | None

  ═══════════════════════════════════════════════════════════════

  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │   ┌────────────────────┐                                    │
  │   │  RMSNorm           │  weight: (1024,)                   │
  │   │  (input_layernorm) │                                    │
  │   └─────────┬──────────┘                                    │
  │             │ (*, 1024)                                     │
  │             ▼                                               │
  │   ┌────────────────────┐                                    │
  │   │  Multi-Head        │                                    │
  │   │  Attention         │  详见第五节                         │
  │   │  (GQA + RoPE)      │                                    │
  │   └─────────┬──────────┘                                    │
  │             │ (*, 1024)                                     │
  │             │                                               │
  │   ────── ⊕ ──────  ← 残差连接: attn_out + residual         │
  │             │ (*, 1024)                                     │
  │             ▼                                               │
  │   ┌────────────────────┐                                    │
  │   │  RMSNorm           │  weight: (1024,)                   │
  │   │  (post_attn_norm)  │                                    │
  │   └─────────┬──────────┘                                    │
  │             │ (*, 1024)                                     │
  │             ▼                                               │
  │   ┌────────────────────┐                                    │
  │   │  MLP (SwiGLU)      │  详见第六节                         │
  │   └─────────┬──────────┘                                    │
  │             │ (*, 1024)                                     │
  │             │                                               │
  │   ────── ⊕ ──────  ← 残差连接: mlp_out + residual          │
  │             │                                               │
  │             ▼                                               │
  │   输出: x: (*, 1024)                                        │
  │                                                             │
  └─────────────────────────────────────────────────────────────┘

  残差流 (Residual Stream):
    第 0 层: residual = embedding_output
    第 i 层: residual = 第 i-1 层的最终输出
    每次 norm 前: x_new = x + residual, 然后 residual = x_new
```

## 五、Attention 模块详解

```
Qwen3Attention

  输入: x: (*, 1024)    positions: (*,)  ← token 位置索引

  ═══════════════════════════════════════════════════════════════

  ┌──────────────────────────────────────────────────────────────┐
  │  Step 1: QKV 线性投影                                       │
  │                                                              │
  │  W_qkv: (4096, 1024)                                        │
  │       = cat([W_q, W_k, W_v], dim=0)                         │
  │                                                              │
  │       W_q: (2048, 1024)   ← 16 heads × 128 head_dim         │
  │       W_k: (1024, 1024)   ←  8 kv_heads × 128 head_dim      │
  │       W_v: (1024, 1024)   ←  8 kv_heads × 128 head_dim      │
  │                                                              │
  │  qkv = x @ W_qkv^T                                           │
  │                                                              │
  │  (*, 1024) ──→ (*, 4096)                                    │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 2: 拆分 Q, K, V                                       │
  │                                                              │
  │  qkv.split([2048, 1024, 1024], dim=-1)                       │
  │                                                              │
  │  q: (*, 2048)                                                │
  │  k: (*, 1024)                                                │
  │  v: (*, 1024)                                                │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 3: Reshape 为多头格式                                  │
  │                                                              │
  │  q: (*, 2048) → (*, 16, 128)     [num_heads, head_dim]      │
  │  k: (*, 1024) → (*, 8, 128)      [num_kv_heads, head_dim]   │
  │  v: (*, 1024) → (*, 8, 128)      [num_kv_heads, head_dim]   │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 4: Q Norm + K Norm                                    │
  │                                                              │
  │  (因为 qkv_bias=False, 所以执行此步骤)                       │
  │                                                              │
  │  q_norm: RMSNorm   weight: (128,)                            │
  │  k_norm: RMSNorm   weight: (128,)                            │
  │                                                              │
  │  对每个 head 独立做 RMSNorm:                                 │
  │                                                              │
  │  q: (*, 16, 128) → (*, 16, 128)                             │
  │  k: (*, 8, 128)  → (*, 8, 128)                              │
  │                                                              │
  │  作用: 稳定 attention score, 防止 softmax 溢出               │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 5: Rotary Position Embedding (RoPE)                   │
  │                                                              │
  │  base (theta) = 1,000,000                                   │
  │  rotary_dim = head_dim = 128                                 │
  │                                                              │
  │  频率计算:                                                   │
  │    inv_freq = 1 / (theta ^ (arange(0, 128, 2) / 128))       │
  │             shape: (64,)                                     │
  │                                                              │
  │    freqs[m] = m × inv_freq      m = 位置索引                │
  │             shape: (64,)                                     │
  │                                                              │
  │  旋转公式 (GPT-J 风格, 前后半各 64 维):                      │
  │                                                              │
  │    q1, q2 = q.chunk(2, dim=-1)   各 (*, heads, 64)          │
  │    cos, sin = cos(freqs), sin(freqs)    各 (*, 64)           │
  │                                                              │
  │    q_rot_1 = q1 × cos - q2 × sin                            │
  │    q_rot_2 = q1 × sin + q2 × cos                            │
  │    q_rot = cat([q_rot_1, q_rot_2], dim=-1)                  │
  │                                                              │
  │    k 同理                                                    │
  │                                                              │
  │  q: (*, 16, 128) → (*, 16, 128)                             │
  │  k: (*, 8, 128)  → (*, 8, 128)                              │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 6: Attention 计算                                     │
  │                                                              │
  │  scale = 1.0 / sqrt(head_dim) = 1.0 / sqrt(128) ≈ 0.0884   │
  │                                                              │
  │  GQA (Grouped Query Attention):                             │
  │    16 个 Q head 分成 8 组, 每组 2 个 Q head                  │
  │    共享同一个 KV head                                        │
  │                                                              │
  │    Q head 0,1  → KV head 0                                  │
  │    Q head 2,3  → KV head 1                                  │
  │    ...                                                       │
  │    Q head 14,15 → KV head 7                                 │
  │                                                              │
  │  对每个 Q head:                                              │
  │                                                              │
  │    scores = (q_h @ k_kv_h^T) × scale                        │
  │      (seq, 128) @ (128, seq) → (seq, seq)                   │
  │                                                              │
  │    因果 mask: scores[i,j] = -inf  当 j > i                  │
  │                                                              │
  │    weights = softmax(scores, dim=-1)                         │
  │      (seq, seq)                                              │
  │                                                              │
  │    attn_out_h = weights @ v_kv_h                             │
  │      (seq, seq) @ (seq, 128) → (seq, 128)                   │
  │                                                              │
  │  所有 head 拼接:                                             │
  │    attn_out: (*, 16, 128)                                   │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 7: Reshape + 输出投影                                 │
  │                                                              │
  │  reshape: (*, 16, 128) → (*, 2048)                          │
  │                                                              │
  │  W_o: (1024, 2048)                                           │
  │                                                              │
  │  output = attn_flat @ W_o^T                                  │
  │                                                              │
  │  (*, 2048) ──→ (*, 1024)                                    │
  └──────────────────────────────────────────────────────────────┘

  Attention 输出: (*, 1024)
```

## 六、MLP 模块详解 (SwiGLU)

```
Qwen3MLP

  输入: x: (*, 1024)

  ═══════════════════════════════════════════════════════════════

  ┌──────────────────────────────────────────────────────────────┐
  │  Step 1: Gate + Up 合并投影                                  │
  │                                                              │
  │  W_gate_up: (6144, 1024)                                     │
  │           = cat([W_gate, W_up], dim=0)                       │
  │                                                              │
  │       W_gate: (3072, 1024)                                   │
  │       W_up:   (3072, 1024)                                   │
  │                                                              │
  │  gate_up_out = x @ W_gate_up^T                               │
  │                                                              │
  │  (*, 1024) ──→ (*, 6144)                                    │
  │                                                              │
  │  输出布局: [gate_out | up_out]                                │
  │              ← 3072 → ← 3072 →                               │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 2: SiLU × Mul (SwiGLU 激活)                           │
  │                                                              │
  │  gate_out, up_out = chunk(2, dim=-1)                         │
  │    gate_out: (*, 3072)                                       │
  │    up_out:   (*, 3072)                                       │
  │                                                              │
  │  activated = SiLU(gate_out) × up_out                         │
  │            = (gate_out × σ(gate_out)) × up_out               │
  │                                                              │
  │  (*, 6144) ──→ (*, 3072)                                    │
  └──────────────────────────┬───────────────────────────────────┘
                             │
                             ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  Step 3: Down 投影                                           │
  │                                                              │
  │  W_down: (1024, 3072)                                        │
  │                                                              │
  │  output = activated @ W_down^T                                │
  │                                                              │
  │  (*, 3072) ──→ (*, 1024)                                    │
  └──────────────────────────────────────────────────────────────┘

  MLP 输出: (*, 1024)
```

## 十一、关键设计特点

```
1. GQA (Grouped Query Attention)
   ┌──────────────────────────────────────────────────┐
   │  Q heads: 16     KV heads: 8                     │
   │                                                  │
   │  Q0  Q1  Q2  Q3  Q4  Q5  ... Q14 Q15            │
   │   ╲  ╱    ╲  ╱    ╲  ╱         ╲  ╱             │
   │   KV0     KV1     KV2    ...   KV7               │
   │                                                  │
   │  每 2 个 Q head 共享 1 个 KV head                │
   │  减少 KV cache 内存 50%                           │
   └──────────────────────────────────────────────────┘

2. Q/K Norm
   ┌──────────────────────────────────────────────────┐
   │  在 RoPE 之前对 Q 和 K 做 RMSNorm               │
   │  每个 head 独立归一化 (head_dim=128)             │
   │                                                  │
   │  作用: 防止 attention score 数值过大              │
   │        稳定 softmax, 避免训练/推理溢出            │
   └──────────────────────────────────────────────────┘

3. RoPE (Rotary Position Embedding)
   ┌──────────────────────────────────────────────────┐
   │  theta = 1,000,000 (比常见的 10,000 大 100 倍)   │
   │                                                  │
   │  高频分量旋转慢 → 捕捉远距离依赖                  │
   │  低频分量旋转快 → 捕捉局部模式                    │
   │                                                  │
   │  位置编码直接作用于 Q/K, 不增加额外参数           │
   └──────────────────────────────────────────────────┘

4. SwiGLU 激活
   ┌──────────────────────────────────────────────────┐
   │  f(x) = SiLU(W_gate · x) ⊙ (W_up · x)          │
   │                                                  │
   │  比 ReLU/GELU 表达能力更强                       │
   │  代价: MLP 需要 3 个权重矩阵 (gate, up, down)    │
   │        intermediate_size = 3072 (而非 4×1024)    │
   └──────────────────────────────────────────────────┘

5. Pre-Norm 架构
   ┌──────────────────────────────────────────────────┐
   │  RMSNorm 在 Attention/MLP 之前                   │
   │  (区别于 Post-Norm: 在之后)                      │
   │                                                  │
   │  训练更稳定, 梯度流更平滑                         │
   └──────────────────────────────────────────────────┘

6. 无 Bias
   ┌──────────────────────────────────────────────────┐
   │  QKV projection: 无 bias                         │
   │  O projection:   无 bias                         │
   │  MLP 全部:      无 bias                          │
   │                                                  │
   │  减少参数量, 现代 LLM 的常见选择                  │
   └──────────────────────────────────────────────────┘

7. Weight Tying
   ┌──────────────────────────────────────────────────┐
   │  Embedding 和 LM Head 共享同一组权重              │
   │                                                  │
   │  节省 ~155M 参数 (151936 × 1024)                 │
   │  语义上: 编码和解码使用同一空间                   │
   └──────────────────────────────────────────────────┘
```

## 十二、逐层详解：做了什么、为什么这样做、为什么可行

> 以下用 $L$ 表示序列长度 (seq_len)，$d$ 表示隐藏维度 (1024)，$H$ 表示 Q 头数 (16)，
> $H_{kv}$ 表示 KV 头数 (8)，$d_h$ 表示头维度 (128)，$d_{ff}$ 表示中间维度 (3072)，
> $V$ 表示词表大小 (151936)。

---

### 1. Embedding — 把整数变成向量

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(L,)$ | $(L,\, d)$ | $(V,\, d)$ |

**做了什么：**

输入是一串整数，比如 `[15339, 419, 374]`，每个整数代表一个词（token）。Embedding 就是一个巨大的查找表 $E \in \mathbb{R}^{V \times d}$，对每个整数 $t$，直接取出第 $t$ 行作为它的向量表示：

$$x_i = E[t_i] \in \mathbb{R}^{d}$$

**为什么这样做：**

整数本身没有任何语义信息——"15339"这个数字和"419"之间没有远近亲疏关系。但神经网络需要连续的、有几何意义的输入。Embedding 把离散的符号映射到一个高维连续空间，在这个空间里，语义相近的词（比如"猫"和"狗"）对应的向量距离会更近。

**为什么可行：**

$V \times d = 151936 \times 1024 \approx 1.55$ 亿个参数，这是一个巨大的"记忆库"。训练过程中，梯度下降会自动把语义相关的词推到空间中相近的位置。这本质上是分布式表示（distributed representation）的思想：用 1024 个浮点数的组合来编码一个词的含义，比 one-hot 编码（151936 维只有一个 1）信息密度高得多。

---

### 2. RMSNorm (Input LayerNorm) — 把向量"拉回标准尺度"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, d)$ | $(d,)$ |

**做了什么：**

对每个 token 的 1024 维向量，先算它所有分量的均方根（RMS），然后用它去除，再乘以一个可学习的缩放因子 $\gamma$：

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \epsilon}} \odot \gamma$$

其中 $\epsilon = 10^{-6}$ 防止除以零，$\gamma \in \mathbb{R}^{d}$ 是可学习参数。

**为什么这样做：**

经过多层网络运算后，隐藏向量的数值范围会不断漂移——有的层输出特别大，有的特别小。这会让后续层的训练变得不稳定（梯度要么爆炸要么消失）。RMSNorm 把每个向量的"长度"拉回到一个相对固定的范围，让每一层的输入都处在一个"舒适区"。

它和 LayerNorm 的区别在于：**不减均值**。因为 LLM 实践中发现减均值几乎没用，省掉这一步可以加速计算。

**为什么可行：**

RMSNorm 只改变向量的"方向"和"缩放"，不改变向量之间的相对关系。$\gamma$ 参数让网络可以自己学回需要的尺度——如果网络觉得某个维度需要更大的值，$\gamma$ 在那个维度上就会学得更大。这是一种"先标准化、再按需调整"的策略。

### 3. QKV Projection — 把隐藏状态变成"提问"、"记忆线索"和"记忆内容"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, d \cdot H + 2 \cdot d \cdot H_{kv})$ = $(*,\, 4096)$ | $(4096,\, 1024)$ |

**做了什么：**

用一个线性变换，把 1024 维的隐藏向量同时投射成三组不同的向量：

$$\begin{bmatrix} q \\ k \\ v \end{bmatrix} = W_{qkv} \cdot x$$

其中：
- $q \in \mathbb{R}^{H \times d_h} = \mathbb{R}^{16 \times 128}$ — Query（"我在找什么"）
- $k \in \mathbb{R}^{H_{kv} \times d_h} = \mathbb{R}^{8 \times 128}$ — Key（"我有什么特征"）
- $v \in \mathbb{R}^{H_{kv} \times d_h} = \mathbb{R}^{8 \times 128}$ — Value（"我的具体内容"）

**为什么这样做：**

Attention 的核心思想是"按需检索"。想象你在图书馆找书：
- **Query** 是你脑子里的问题——"我想了解关于什么的信息"
- **Key** 是每本书封面上的标签——"这本书是关于什么的"
- **Value** 是书的实际内容

通过比较 Query 和所有 Key 的相似度，决定应该重点看哪些 Value。

把 QKV 合并成一个矩阵乘法（而非三次独立乘法），是因为 GPU 擅长大矩阵运算，一次大乘法比三次小乘法快得多。

**为什么可行：**

线性变换 $W_{qkv}$ 有 $4096 \times 1024 \approx 420$ 万个参数，足够学到丰富的投射方式。同一个隐藏状态 $x$ 被投射到三个不同的子空间，分别承担不同的角色——这是注意力机制的基础。

---

### 4. Split + Reshape — 把合并结果拆成多头格式

| 输入 Shape | 输出 Shape |
|-----------|-----------|
| $(*,\, 4096)$ | $q$: $(*,\, 16,\, 128)$，$k$: $(*,\, 8,\, 128)$，$v$: $(*,\, 8,\, 128)$ |

**做了什么：**

先沿最后一维切分：$q$ 取前 2048 维，$k$ 取中间 1024 维，$v$ 取后 1024 维。然后把每个 $q, k, v$ 从"一长条"重新排列成"多头矩阵"：

$$q: (*,\, 2048) \xrightarrow{\text{reshape}} (*,\, 16,\, 128)$$

即把 2048 维拆成 16 组，每组 128 维，代表一个"注意力头"。

**为什么这样做：**

多头注意力（Multi-Head Attention）的核心思想是：**让模型同时从多个不同的角度去关注输入**。比如一个头可能关注语法结构，另一个头关注语义关系，还有一个头关注位置信息。

如果只用一个头（$H=1, d_h=2048$），模型只能学到一种"关注模式"。分成 16 个头，每个头独立地学习自己的关注模式，最后合并，信息更丰富。

**为什么可行：**

这纯粹是一个 reshape 操作，没有任何计算和参数。它只是把数据重新组织，让后续的 attention 计算可以按头并行执行。数学上等价于对每个头独立做 attention，只是实现上更高效。

---

### 5. Q Norm + K Norm — 给 Q 和 K 做"体检校准"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $q$: $(*,\, H,\, d_h)$ | $(*,\, H,\, d_h)$ | $(d_h,)$ |
| $k$: $(*,\, H_{kv},\, d_h)$ | $(*,\, H_{kv},\, d_h)$ | $(d_h,)$ |

**做了什么：**

对 Q 和 K 的**每个头**独立做 RMSNorm：

$$q_{h}^{\text{norm}} = \text{RMSNorm}(q_h), \quad k_{h}^{\text{norm}} = \text{RMSNorm}(k_h)$$

注意：是对 $d_h = 128$ 这个维度做归一化，每个头有自己的 $\gamma$。

**为什么这样做：**

Attention 的下一步要算 $q \cdot k^T$（点积），这个点积的大小直接取决于 $q$ 和 $k$ 向量的模长。如果某些头的 $q, k$ 模长特别大，点积结果就会特别大，softmax 之后几乎所有权重都集中到一个位置上（变成了 one-hot），attention 就失去了"软分配"的意义。

Q/K Norm 把每个头的 Q 和 K 向量都归一化到相似的尺度，确保点积结果在一个合理范围内。

**为什么对 V 不做 Norm：**

V 不参与点积计算，它只是被加权求和的"内容"，模长大一点小一点不影响 softmax 的分布。

**为什么可行：**

RMSNorm 保留了向量的方向（即语义信息），只统一了长度。$\gamma$ 参数允许网络在需要时恢复某些维度的尺度。这是 Qwen3 相比早期 LLM（如 Llama 2）的改进——Llama 2 没有 Q/K Norm，在长序列推理时偶尔会出现 attention score 爆炸的问题。

### 6. RoPE (Rotary Position Embedding) — 给向量"拧上位置信息"

| 输入 Shape | 输出 Shape |
|-----------|-----------|
| $q$: $(*,\, H,\, d_h)$，$k$: $(*,\, H_{kv},\, d_h)$ | 同输入，shape 不变 |

**做了什么：**

把 $q$ 和 $k$ 的 128 维分成前后两半（各 64 维），然后根据 token 的位置 $m$ 做旋转：

$$\begin{bmatrix} q_1' \\ q_2' \end{bmatrix} = \begin{bmatrix} \cos(m\theta) & -\sin(m\theta) \\ \sin(m\theta) & \cos(m\theta) \end{bmatrix} \begin{bmatrix} q_1 \\ q_2 \end{bmatrix}$$

其中 $\theta_i = \frac{1}{\text{base}^{2i/d_h}}$，$i = 0, 1, \ldots, d_h/2 - 1$，$\text{base} = 10^6$。

实际上是对 64 对 $(q_{2i}, q_{2i+1})$ 分别做不同角度的二维旋转，每对旋转角度为 $m \cdot \theta_i$。

**为什么这样做：**

Transformer 本身是"位置盲"的——它不知道哪个 token 在前哪个在后。必须注入位置信息。

RoPE 的精妙之处在于：**它不改变 Q 和 K 本身，而是旋转它们，使得两个位置的 Q 和 K 做点积时，结果自然地包含了相对位置信息**。具体来说：

$$q_m \cdot k_n = f(q, m) \cdot f(k, n) = g(q, k, m - n)$$

点积结果只取决于相对距离 $m - n$，而不是绝对位置 $m$ 或 $n$。

**为什么 base = 1,000,000：**

$\theta_i$ 的旋转周期是 $2\pi / \theta_i$。base 越大，$\theta_i$ 越小，旋转越慢。这意味着即使是相距很远的 token，它们的相对位置信息也不会"转回原点"而混淆。Qwen3 用 100 万（比 Llama 的 1 万大 100 倍），就是为了支持更长的上下文（32768 tokens）。

**为什么可行：**

RoPE 是纯数学变换，没有额外参数。旋转操作保持向量的模长不变（旋转矩阵是正交矩阵），所以不会破坏前面 Norm 层做好的尺度控制。它把位置信息"编码进"了 Q 和 K 的角度中，让后续的 $q \cdot k^T$ 自然感知到距离。

---

### 7. Attention 计算 — 让每个 token "看看"其他 token

| 输入 Shape | 输出 Shape |
|-----------|-----------|
| $q$: $(*,\, H,\, d_h)$，$k$: $(*,\, H_{kv},\, d_h)$，$v$: $(*,\, H_{kv},\, d_h)$ | $(*,\, H,\, d_h)$ |

**做了什么：**

对每个 Q 头 $h$，找到它对应的 KV 头 $h' = h \div (H / H_{kv})$（GQA 映射），然后：

$$\text{scores}_{ij} = \frac{q_{i,h} \cdot k_{j,h'}}{\sqrt{d_h}}$$

$$\text{weights}_{ij} = \text{softmax}_j(\text{scores}_{ij}) \quad \text{（因果 mask：} j > i \text{ 时 } \text{scores}_{ij} = -\infty\text{）}$$

$$o_{i,h} = \sum_j \text{weights}_{ij} \cdot v_{j,h'}$$

**为什么除以 $\sqrt{d_h}$：**

$q$ 和 $k$ 都是 128 维向量，它们的点积是 128 个分量乘积之和。维度越高，点积的方差越大（约等于 $d_h$ 倍单分量方差）。除以 $\sqrt{128} \approx 11.3$ 把方差拉回到 1 附近，让 softmax 的输入处在一个"不饱和"的范围——否则 softmax 输出会过于尖锐，梯度几乎为零。

**为什么用因果 mask：**

语言模型的任务是"根据前面的词预测下一个词"。位置 $i$ 的 token 只能看到位置 $\leq i$ 的 token，不能偷看后面的内容。把 $j > i$ 的 score 设为 $-\infty$，softmax 后这些位置的权重就变成 0。

**GQA 为什么可行：**

标准 MHA 中 Q 和 KV 头数相同（16:16），每个 Q 头有自己专属的 KV 头。GQA 让多个 Q 头共享同一个 KV 头（16:8 = 2:1），KV cache 的内存直接减半。实验表明，Q 头的数量对模型能力影响大，但 KV 头数量可以大幅压缩而不明显降低质量——因为不同的 Q 头可以学会从同一组 KV 中提取不同的信息。

---

### 8. Reshape + O Projection — 把多头的结果合并并投射回隐藏空间

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, H,\, d_h)$ → reshape → $(*,\, H \cdot d_h)$ | $(*,\, d)$ | $(d,\, H \cdot d_h)$ = $(1024,\, 2048)$ |

**做了什么：**

先把 16 个头的输出拼接成一个 2048 维向量，再用一个线性变换投射回 1024 维：

$$o = W_o \cdot \text{concat}(o_1, o_2, \ldots, o_H)$$

**为什么这样做：**

16 个头各自独立地"看到"了不同的信息，但它们的结果还停留在各自的 128 维子空间里。O Projection 的作用是让这些信息**交叉融合**——比如头 3 发现的语法关系和头 7 发现的语义关系，可以在这一层线性变换中互相影响。

**为什么投射回 1024 维：**

整个模型的"残差流"（residual stream）始终是 1024 维。Attention 内部可以扩展（16×128=2048），但最终必须压缩回 1024 维，才能和残差相加。这就像一个"扩张-压缩"的瓶颈结构：先扩展维度让多头有足够空间工作，再压缩回来保持残差流的一致性。

---

### 9. 残差连接 (Residual Connection) — 让信息"直通"

| 操作 | Shape |
|------|-------|
| $x_{\text{new}} = x_{\text{attn}} + x_{\text{residual}}$ | $(*,\, d)$ |

**做了什么：**

把 Attention 的输出和进入这一层之前的原始输入（residual）直接相加。

**为什么这样做：**

如果没有残差连接，信息每经过一层就会被"变换"一次。经过 28 层之后，原始信息可能被变换得面目全非，梯度也很难回传（梯度消失/爆炸）。

残差连接的本质是：**每一层只需要学习"增量"（残差），而不是从头学习完整的映射**。第 $i$ 层的输出可以写成：

$$x_i = x_0 + \sum_{j=1}^{i} F_j(x_{j-1})$$

其中 $F_j$ 是第 $j$ 层的 Attention + MLP。即使某一层的 $F_j$ 学得很差（接近零），信息仍然可以通过 $x_0$ 直接传到后面的层。

**为什么可行：**

加法操作保持维度不变，所以残差流始终是 1024 维。梯度回传时，$\frac{\partial x_i}{\partial x_0} = 1 + \sum \frac{\partial F_j}{\partial x_0}$，即使 $\frac{\partial F_j}{\partial x_0}$ 很小，梯度至少是 1，不会消失。这是 ResNet（2015）以来深度学习最重要的技巧之一。

---

### 10. Post-Attention RMSNorm — 给 MLP 准备"干净"的输入

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, d)$ | $(d,)$ |

**做了什么：**

和前面的 Input RMSNorm 完全相同的操作，只是位置在 Attention 之后、MLP 之前。

**为什么这样做：**

Attention 的输出经过残差相加后，数值范围可能又发生了漂移。MLP 层对输入的尺度比较敏感（尤其是 SiLU 激活函数在输入过大时会饱和），所以在进入 MLP 之前再做一次归一化。

这就是 **Pre-Norm** 架构的特点：每个子层（Attention、MLP）之前都有一次 Norm。相比 Post-Norm（子层之后做 Norm），Pre-Norm 训练更稳定，虽然最终效果可能略差，但对于大模型来说稳定性远比微小的效果差异重要。

---

### 11. Gate + Up Projection — 把信息扩展到高维"工作空间"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, 2 \cdot d_{ff})$ = $(*,\, 6144)$ | $(6144,\, 1024)$ |

**做了什么：**

一个线性变换把 1024 维扩展到 6144 维，输出被拆成两部分：

$$\begin{bmatrix} g \\ u \end{bmatrix} = W_{\text{gate\_up}} \cdot x$$

其中 $g \in \mathbb{R}^{3072}$（gate 分支）和 $u \in \mathbb{R}^{3072}$（up 分支）。

**为什么这样做：**

1024 维的隐藏空间太"拥挤"了——它需要同时编码语法、语义、位置、逻辑等各种信息。MLP 的作用是把信息扩展到一个更宽敞的空间（3072 维），在那里做更精细的"思考和加工"，然后再压缩回来。

这类似于人脑的工作方式：在工作记忆（有限容量）和长期记忆（大容量）之间来回转移信息。

**为什么是 3072 而不是更大：**

SwiGLU 需要两组投影（gate 和 up），所以总参数是 $2 \times 3072 \times 1024 \approx 630$ 万。如果用传统的 ReLU MLP（只有 up 和 down），要达到相同的参数量需要 $d_{ff} \approx 4096$。SwiGLU 用 3072 就能达到 4096 的效果，因为门控机制提供了额外的表达能力。

---

### 12. SiLU × Mul (SwiGLU 激活) — 选择性地"放大"有用信息

| 输入 Shape | 输出 Shape |
|-----------|-----------|
| $(*,\, 2 \cdot d_{ff})$ = $(*,\, 6144)$ | $(*,\, d_{ff})$ = $(*,\, 3072)$ |

**做了什么：**

把 6144 维拆成 $g$（前 3072 维）和 $u$（后 3072 维），然后：

$$\text{output} = \text{SiLU}(g) \odot u = \big(g \cdot \sigma(g)\big) \odot u$$

其中 $\sigma$ 是 sigmoid 函数，$\odot$ 是逐元素乘法。

**为什么这样做：**

这里 $g$ 是"门"（gate），$u$ 是"内容"（value）。SiLU(g) 的输出范围大致在 $(-0.28, +\infty)$：
- 当 $g_i$ 很大时，$\text{SiLU}(g_i) \approx g_i$，门"打开"，$u_i$ 的信息通过
- 当 $g_i$ 很小时（负数），$\text{SiLU}(g_i) \approx 0$，门"关闭"，$u_i$ 的信息被抑制

这比 ReLU（只能开/关）和 GELU（平滑版 ReLU）更灵活——门可以"半开"，可以有负值，可以放大。

**为什么可行：**

SiLU（也叫 Swish）是 Google Brain 在 2017 年通过 NAS 搜索发现的激活函数。它结合了 ReLU 的简洁性和 GELU 的平滑性。乘以 $u$ 之后，模型可以学到"对于某些输入，某些特征应该被放大；对于另一些输入，同样的特征应该被抑制"——这是一种条件计算（conditional computation），比固定的 ReLU 表达能力更强。

---

### 13. Down Projection — 把加工后的信息压缩回残差流

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d_{ff})$ = $(*,\, 3072)$ | $(*,\, d)$ = $(*,\, 1024)$ | $(1024,\, 3072)$ |

**做了什么：**

$$x_{\text{mlp}} = W_{\text{down}} \cdot \text{activated}$$

把 3072 维压缩回 1024 维，然后和残差相加。

**为什么这样做：**

MLP 在 3072 维的"工作空间"里完成了信息的加工和筛选，现在需要把结果"汇报"回 1024 维的残差流。Down Projection 就是这个"汇报"的过程——它学到了哪些加工后的信息是重要的，应该传回主通道。

**为什么 MLP 整体是"先扩后缩"：**

整个 MLP 的结构是 $1024 \to 6144 \to 3072 \to 1024$，形成一个"沙漏"形。扩展维度是为了让非线性激活有更大的操作空间（更多的维度意味着更多的"特征槽"可以被独立地开关），压缩回来是为了和残差流对接。这和人类认知中的"发散思维→聚焦决策"过程类似。

---

### 14. × 28 层堆叠 — 逐层构建越来越抽象的表示

**做了什么：**

把上面 2~13 步组成的 Decoder Layer 重复 28 次，每层的输出作为下一层的输入。

**为什么是 28 层：**

每一层做两件事：
1. **Attention**：让 token 之间交换信息（"这个词和那个词有什么关系"）
2. **MLP**：对每个 token 独立做非线性变换（"根据我收集到的信息，更新我的表示"）

层数越多，模型能学到的"推理步骤"就越多。研究表明，浅层主要学习语法和局部模式，深层学习语义和抽象推理。28 层对于 0.6B 参数的模型是一个平衡点——足够深以学到有用的表示，又不至于因为太深而难以训练或推理太慢。

**为什么可行：**

残差连接是堆叠多层的关键。没有它，28 层的网络几乎不可能训练。有了它，每一层只需要学习一个"小的改进"，28 个"小的改进"累加起来就形成了强大的表示能力。理论上，28 层 Transformer 可以表示深度为 28 的组合函数，这是浅层网络做不到的。

---

### 15. Final RMSNorm — 最后一次"整理"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, d)$ | $(d,)$ |

**做了什么：**

和第 2 步、第 10 步的 RMSNorm 完全一样。先把最后一层的 MLP 输出和残差相加，再做一次归一化。

**为什么这样做：**

经过 28 层之后，残差流中的向量尺度可能已经发生了很大变化。在送入 LM Head 之前做最后一次归一化，确保 LM Head 收到的输入在一个稳定的范围内。

如果不做这一步，LM Head 的线性变换可能会收到尺度不一致的输入，导致某些 token 的 logits 异常大或小，影响采样质量。

---

### 16. LM Head — 把隐藏状态翻译成"下一个词的概率"

| 输入 Shape | 输出 Shape | 权重 Shape |
|-----------|-----------|-----------|
| $(*,\, d)$ | $(*,\, V)$ = $(*,\, 151936)$ | $(V,\, d)$ = $(151936,\, 1024)$ |

**做了什么：**

对每个 token 位置的隐藏向量 $h \in \mathbb{R}^{1024}$，计算它和词表中每个词的"相似度得分"：

$$\text{logits}_v = h \cdot E_v \quad \text{for } v = 1, 2, \ldots, V$$

其中 $E_v$ 是 Embedding 矩阵的第 $v$ 行（因为 tie_word_embeddings=True，LM Head 和 Embedding 共享权重）。

然后通过 softmax 和采样得到下一个 token：

$$p_v = \frac{\exp(\text{logits}_v / T)}{\sum_{v'} \exp(\text{logits}_{v'} / T)}$$

其中 $T$ 是温度参数（控制随机性）。

**为什么这样做：**

模型经过 28 层处理后，最后一个 token 的隐藏向量 $h$ 包含了"到目前为止所有上下文"的信息。LM Head 要回答的问题是："基于这些信息，下一个最可能出现的词是什么？"

它通过计算 $h$ 和词表中每个词向量的点积来衡量"匹配程度"——点积越大，说明 $h$ 的语义和那个词越接近。

**为什么可以共享 Embedding 权重：**

Embedding 把"词"映射到 1024 维空间，LM Head 把 1024 维空间映射回"词"。它们本质上是在同一个空间里做正反方向的转换。如果"猫"的 embedding 向量是 $e_{\text{cat}}$，那么当 $h$ 接近 $e_{\text{cat}}$ 时，$h \cdot e_{\text{cat}}$ 就会很大，模型就会倾向于输出"猫"。共享权重不仅省了 1.55 亿参数，还保证了编码和解码使用同一套语义空间。
